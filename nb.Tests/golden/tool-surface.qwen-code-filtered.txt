=== run_shell_command
--- description
Execute a shell command and return the output.
Commands run in: <CWD>
Shell: <SHELL>

Parameters:
- description: Brief explanation (5-10 words) of what this command does and why. Required.
- command: The shell command to execute.
- timeout_seconds: Optional timeout (default 120s).

Returns stdout, stderr, and exit code. Large outputs are truncated.
Commands require user approval before execution.

{
  "type": "object",
  "properties": {
    "command": {
      "type": "string",
      "description": "The shell command to execute."
    },
    "is_background": {
      "type": "boolean",
      "description": "Whether to run the command in the background."
    },
    "description": {
      "type": "string",
      "description": "Brief explanation of what this command does and why."
    },
    "timeout": {
      "type": "number",
      "description": "Timeout in milliseconds for foreground commands."
    },
    "directory": {
      "type": "string",
      "description": "Working directory for command execution."
    }
  },
  "required": [
    "command",
    "is_background"
  ]
}

=== read_file
--- description
Read file contents with line numbers.
Paths are relative to: <CWD>

Supports text (with offset/limit pagination), PDF (text extraction), and images (.jpg/.jpeg/.png, returned as base64 for vision).

Parameters:
- path: File path (absolute or relative to working directory)
- offset: 1-based line number to start from (default: 1, text only)
- limit: Max lines to return (default: 2000, text only)
--- schema
{
  "type": "object",
  "properties": {
    "file_path": {
      "type": "string",
      "description": "The path to the file to read."
    },
    "offset": {
      "type": "number",
      "description": "1-based line number to start from."
    },
    "limit": {
      "type": "number",
      "description": "Maximum number of lines to return."
    }
  },
  "required": [
    "file_path"
  ]
}

=== edit
--- description
Targeted string replacement in an existing file.
Paths are relative to: <CWD>

Parameters:
- path: File path (absolute or relative to working directory)
- old_string: Exact text to find (must match including whitespace and indentation)
- new_string: Replacement text
- replace_all: Replace all occurrences (default: false)

Fails if old_string is not found. Fails if old_string is not unique when replace_all is false — add more surrounding context to make it unique.
--- schema
{
  "type": "object",
  "properties": {
    "file_path": {
      "type": "string",
      "description": "The path to the file to modify."
    },
    "old_string": {
      "type": "string",
      "description": "The exact text to replace."
    },
    "new_string": {
      "type": "string",
      "description": "The text to replace it with."
    },
    "replace_all": {
      "type": "boolean",
      "description": "Replace every occurrence instead of requiring a unique match."
    }
  },
  "required": [
    "file_path",
    "old_string",
    "new_string"
  ]
}
